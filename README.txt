# Our Little Love Story — website template

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Publish for free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository (for example `our-love-story`).
2. Upload `index.html` and the entire `assets` folder. Keep the folder structure unchanged.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The Pages screen will show the shareable URL.

The site uses only local files and plain HTML/CSS/JavaScript—no paid services or external libraries.
